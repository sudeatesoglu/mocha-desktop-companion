# Skin format

A skin decides how Mocha looks. It is plain data, a sprite sheet and a manifest, so new skins need no code changes.

```
skins/<skin-name>/
├── sprite.png      all animation frames in one image
└── manifest.json   which frames make up each animation
```

The bundled placeholder skin lives in [`apps/desktop/src/renderer/skins/default`](../apps/desktop/src/renderer/skins/default). It is generated by `pnpm --filter @mocha/desktop generate:skin` and will be replaced by hand-drawn art.

## Sprite sheet

- **PNG with transparency.** Transparent pixels are click-through: clicks there reach the app underneath Mocha.
- **Frames on a grid** of equal cells, no padding and no gaps. The image size must be a whole number of frames in both directions.
- **Frame size: 48×48** for the desktop overlay. The app scales it up by an integer factor without smoothing, so pixels stay crisp.
- **Frames are numbered row by row**, starting at 0 in the top-left cell:

  ```
  ┌───┬───┬───┬───┐
  │ 0 │ 1 │ 2 │ 3 │
  ├───┼───┼───┼───┤
  │ 4 │ 5 │ 6 │ 7 │
  └───┴───┴───┴───┘
  ```

- **Leave the pupil out.** Draw the eye white but not the pupil: the app draws a 2×2 pupil at the frame's `eye` anchor, so it can follow the cursor and turn red on hover without extra frames.

### Palette

The placeholder uses an eight-color ink palette. Skins may use any colors, but staying close to it keeps Mocha's look consistent.

| Color | Hex | Use |
| --- | --- | --- |
| Ink black | `#0d0b0e` | outlines, pupil |
| Deep shadow | `#2b2630` | body |
| Mid gray | `#5a5260` | dithering, lower beak |
| Light gray | `#a8a1a6` | beak, "z"s |
| Paper white | `#f2eee6` | eye white |
| Blood red | `#c2213a` | hat band, hover pupil |
| Dark red | `#7a1020` | shading on red |
| Mocha brown | `#4a3427` | optional warm accent |

## Manifest

```json
{
  "schemaVersion": 1,
  "name": "Mocha",
  "author": "Your name",
  "image": "sprite.png",
  "frameSize": { "width": 48, "height": 48 },
  "animations": {
    "idle": {
      "loop": true,
      "frames": [
        { "index": 0, "durationMs": 800, "anchors": { "eye": { "x": 18, "y": 19 } } },
        { "index": 1, "durationMs": 800, "anchors": { "eye": { "x": 18, "y": 20 } } }
      ]
    }
  }
}
```

| Field | Rules |
| --- | --- |
| `schemaVersion` | Must be `1`. |
| `name` | 1–64 characters. |
| `author` | Optional, 1–64 characters. |
| `image` | A bare file name ending in `.png`, such as `sprite.png`. No folders or URLs: a skin can only use its own files. |
| `frameSize` | Whole pixels, 1–256 per side. The desktop overlay requires 48×48. |
| `animations` | See below. Unknown animation names are rejected. |

### Animations

| Name | When it plays | Required |
| --- | --- | --- |
| `idle` | Default state: breathing | Yes |
| `blink` | Now and then while idle | No |
| `look` | While Mocha watches the cursor | No |
| `hop` | When petted | No |
| `sleep` | While the user is away | No |

Every animation has a `loop` flag and at least one frame. A missing optional animation falls back to `idle`.

### Frames

| Field | Rules |
| --- | --- |
| `index` | Cell in the sheet (0-based, row by row). |
| `durationMs` | How long the frame shows, 16–60000 ms. 16 ms is one display frame at 60 Hz; shorter frames would never be seen. |
| `anchors` | Optional points inside the frame, in frame pixels (top-left is 0,0). |

### Anchors

| Anchor | Meaning |
| --- | --- |
| `eye` | Top-left pixel of the 2×2 pupil when Mocha looks straight ahead. Omit it on frames where the eye is closed: no pupil is drawn. |
| `beak` | Tip of the beak, where food and speech bubbles attach. |
| `head` | Top of the head (or hat), where hearts and "z"s appear. |

Anchors move with the drawing. If a frame lowers the head by one pixel, its anchors move down by one pixel too, so effects stay attached.

## Validation

Skins are checked when they load, in two stages:

1. **Manifest:** structure and rules above. All problems are reported at once, each with its location, for example `animations.idle.frames.0.durationMs: Too small: expected number to be >=16`.
2. **Image:** after the sprite sheet loads, its size must be a whole number of frames and every frame index must exist in it.

A skin that fails either stage is not used. The error is written to the app log and Mocha falls back to the built-in placeholder, so it never disappears.

## Tips for Aseprite or Pixelorama

- Draw each frame at 48×48 in its own animation frame, then export a sprite sheet **by rows** with **no padding, no trimming and no border**.
- Keep anchor positions on a separate hidden layer (one pixel per anchor) while drawing, then copy the coordinates into the manifest.
- Use the same frame more than once in an animation to hold a pose without drawing it twice (the placeholder's blink does this).
